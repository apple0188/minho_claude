1. 배경 — 상담에서 확인한 내용

플랜듀가 하는 일

  • 단순 강사 연결(수수료 20%)이 아니라 기업교육 컨설팅 — "우리 회사 2박 3일 연수, 어디에 맡기고 무엇으로 채울까"를 대신 설계
  • 대표님 얼굴과 이름이 곧 신뢰인 사업 (부동산처럼 얼굴 걸고 하는 일)
  • 최근 시장: AI 강의 수요 급증, 기존 강사 강의는 감소

지금의 어려움

  • 홈페이지가 필요하지만 만들 시간이 없음
  • 블로그를 꾸준히 해야 하는데 바빠서 못 함
  • 강사 관리, 단체 문자, 세금계산서 발행을 손으로 처리
  • AI를 배워 봤지만 직접 굴릴 시간이 없음
프로젝트 한 줄 정의 — 플랜듀를 "강사 소개소"가 아닌 "기업교육을 설계하는 컨설팅 브랜드"로 보이게 하고, 반복 업무는 자동화해서 대표님이 영업·컨설팅에만 쓰는 시간을 늘린다.

2. 목표와 성공 기준

목표3개월 후 기준
온라인 신뢰 채널 확보대표 브랜딩 홈페이지 오픈, 기업 담당자 교육 문의 폼 접수 시작
꾸준한 콘텐츠AI 초안 → 대표님 승인 → 발행 체계로 주 2편, 3개월 내 최소 16편 발행
강사 운영 시간 절감강사 DB 일원화, 일정·안내 문자를 클릭 한 번으로 단체 발송
정산 실수 제로교육 완료 처리 시 전자세금계산서 자동 발행, 미발행·미수금 한눈에 확인

3. 작업 범위 — 4개 모듈

모듈 A

대표 브랜딩 홈페이지

  • 메인: 대표 얼굴·메시지 중심 히어로
  • 서비스: 교육 컨설팅 / 커리큘럼 설계 / 강사 매칭 / 운영 대행
  • 진행 프로세스, 대표 프로그램, 고객사·후기
  • 기업 교육 문의 폼 → 대표님 휴대폰 알림
  • 칼럼(블로그) 게시판, 반응형, 기본 SEO
모듈 B

블로그 콘텐츠 자동화

  • 주제 캘린더(기업교육 트렌드, 연수 기획 팁, AI 교육 등)
  • AI가 대표님 톤으로 초안 작성 → 카톡/메일로 승인 요청
  • 승인 시 홈페이지 칼럼 자동 게시
  • 네이버 블로그는 발행용 원고·이미지 패키지 제공(반자동)
    ※ 네이버는 블로그 자동 게시 API를 제공하지 않음
모듈 C

강사 관리 시스템

  • 강사 DB: 분야·지역·강사료·이력·평가
  • 교육 건별 강사 배정 및 일정 관리
  • 강사·담당자 대상 단체 문자(알림톡) 템플릿 발송
  • 대표님이 익숙한 화면(구글 시트 기반 관리자) 우선
모듈 D

세금계산서 자동 발행

  • 전자세금계산서 발행 API 연동(팝빌·바로빌 등 중 선택)
  • 교육 완료 → 발행 요청 → 대표님 확인 후 일괄 발행
  • 월별 매출·미수금 현황표 자동 생성

전체 흐름

① 문의홈페이지 폼 접수, 휴대폰 알림
→
② 컨설팅니즈 분석, 커리큘럼 제안
→
③ 강사 배정강사 DB에서 선택
→
④ 안내 발송강사·담당자 단체 문자
→
⑤ 교육 완료세금계산서 자동 발행
→
⑥ 콘텐츠화사례를 칼럼으로 발행

대표님은 ②번 컨설팅에만 시간을 쓰시고, 나머지는 시스템이 처리하도록 설계합니다.

5. 운영 방식 — "바빠지면 제 건 잘 챙겨 주실까요?"에 대한 답

  • 전용 소통방 하나로 요청·승인·자료를 모두 처리 (카카오톡 단톡 또는 노션 페이지)
  • 매주 금요일 주간 리포트: 이번 주 한 일 / 다음 주 할 일 / 대표님 확인 필요 사항
  • 모든 자동화는 플랜듀 명의 계정으로 구축 — 언제든 대표님이 직접 쓰실 수 있는 구조
  • 모든 작업은 체크리스트·자동화로 표준화해 담당자 일정과 무관하게 같은 품질 유지

6. 대표님께 받을 자료

  • 대표님 프로필 사진(정면·상반신), 약력
  • 로고 파일(없으면 홈페이지용 워드마크 제작)
  • 교육 실적, 고객사 목록(공개 가능 범위), 후기
  • 대표 교육 프로그램 3~5개 소개
  • 현재 강사 리스트(엑셀 등 어떤 형식이든)
  • 자주 보내는 문자 문구
  • 사업자등록증, 최근 세금계산서 발행 내역 샘플
  • 도메인 보유 여부, 기존 블로그 주소

7. 3개월 이후 — 연장 로드맵 (선택)

옵션내용

자동화 고도화교육 만족도 설문 자동 발송 · 결과 리포트, 고객사 재계약 알림, 제안서 자동 생성
