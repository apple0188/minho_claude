# 플랜듀 (PLANDUE) 프로젝트

맞춤형 기업교육 회사 **플랜듀**의 홍보 + 업무 자동화 3개월 프로젝트.
고객 담당: 이현아 팀장님 (카톡에서 사용자를 "대표님"이라 부름).

- `통화 모모_261111_173141`: 상담 직후 통화 (요약만 참고)

## 상담에서 확인한 사실
- 사업: 기업·보험사·공공기관 대상 **거의 100% 맞춤형** 교육. 강의, 힐링 워크숍(외부 지역, 대관·식사까지), 외부 연수·필드 트립, 원데이 클래스
- 슬로건(팀장님이 직접 정함): "핏하게, 그 회사에 핏을 맞춰 드린다" → 시안에서는 **"교육에 딱, 핏을 맞추다"**
- 홈페이지: **얼굴·개인 브랜딩 X, 회사 중심.** 원페이지, 오프닝 모션, 모바일, 대표 인사말 없음. 버튼은 "섭외하기 / 교육 프로그램 문의 / 지난 교육 보기". 소개서 대신 링크로 보내는 용도
- 필요한 것(팀장님 말): 블로그, 홈페이지, 인스타(비즈니스), 스케줄 관리, 강사 일정 리마인드, 계산서, 입금 확인
- 현재 상태: 홈페이지·호스팅 없음. 블로그·인스타는 거의 안 함. 일정은 엑셀, 강사와는 카톡. 강사가 장소를 착각한 사고 경험 있음
- 정해진 방식
  - 카페24(호스팅 월 약 1,500원) + 도메인(연 약 2만원)은 팀장님 명의로 가입해 계정 공유
  - 팝빌 세금계산서 건당 약 200원
  - 강사 문자는 전날 + 당일 오전(티맵 링크), 강의 후 입금 안내
- 팀장님의 걱정
  - "내가 사고 나면 아무도 모른다"
  - 블로그에 강사가 노출되면 고객과 직거래할 위험 → 강사명·고객사명은 비공개로 쓰기로 함
  - 세금계산서가 국세청에 이틀 늦게 반영됨
- 3개월 뒤: 팀장님 노트북에 세팅해서 직접 운영, 또는 **월 200만 원 연장**(유튜브 쇼츠·릴스 포함, 범위에 따라 조정)
- 장기 협업 소재: 강사 양성 과정, 소규모 AI 강의(5만 원대) → 1:1 코칭(약 40만 원) → 컨설팅
- 금액: 700만 원(사용자가 **부가세 별도로 확정**). 상담에서 분할 결제 이야기는 없었음

## 망설이는 고객 대응 전략
- 지금은 거절이 아니라 큰 결정 직후의 불안으로 본다. 설득하지 말고 결정 부담을 줄인다
- 계약서를 먼저 보내지 않는다. **팀장님이 정한 슬로건이 들어간 시안**을 선물처럼 먼저 보낸다
- 700만 원을 한 번에 결정하게 하지 말고 **월 단위로 쪼갠다**(240/230/230, 매달 중단 가능). 시작 문턱을 낮추는 것
- 팀장님의 가장 큰 걱정은 "내가 없으면 안 돌아간다". 자동화는 이걸 해결하는 일로 이야기한다
- 연락은 내일 한 번, 3~4일 뒤 한 번. 두 번째 연락은 "금액인지 시기인지" 묻는 질문으로 끝낸다
