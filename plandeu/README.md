# 플랜듀 프로젝트

기업교육 컨설팅 회사 **플랜듀**의 홈페이지 + 업무 자동화 3개월 프로젝트.

## 계약 요약 (2026-11-11 통화 기준)
- 고객: 플랜듀 팀장(대표)님. 단순 강사 연결(수수료 20%)이 아니라 **기업교육 컨설팅** 업체. 예를 들어 "2박 3일 연수를 어디에 맡기고 무엇으로 채울지"를 설계해 줌. 대표님 얼굴·이름이 곧 브랜드.
- 금액·기간: **3개월 700만 원, 부가세 별도** (합계 770만 원, 2026-11-11 확정)
- 범위: ① 홈페이지 ② 블로그 자동화 ③ 강사 관리 시스템(단체 문자) ④ 세금계산서 자동 발행
- 연장 옵션: 유튜브 촬영·편집 대행, 자동화 고도화, 셀프 운영 전환
- 상호 소개: 강사·강의를 소개해 성사되면 10% (계약서 제16조, 상세 조건은 건별 합의)
- 고객 우려: "바빠지면 내 건 잘 챙겨 줄까?" → 주간 리포트와 시스템화로 답함 (기획서 5장)
